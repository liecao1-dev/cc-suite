# 派遣给 Claude

正常情况下，项目级 `UserPromptSubmit` 钩子会在模型收到 `$claude` 前打开键盘选择器，
保存一次性配置并阻止这条触发消息进入模型。

若你现在能读到本段内容，说明钩子没有启用：

- 不要替 Claude 完成任务，也不要显示编号配置列表。
- 告诉用户运行项目范围同步器，并确认 Codex 已信任当前项目。
- 正确流程始终是：输入 `$claude` → 选择配置 → 再发送任务。
- 每个新任务和追问都必须重新输入 `$claude`；配置不会粘住。
