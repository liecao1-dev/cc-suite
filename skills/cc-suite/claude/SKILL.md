# 派遣给 Claude

正常情况下，范围内的 composer 代理会在补全菜单选择 `$claude` 的 Enter/Tab 到达
Codex 前打开键盘选择器。`$claude` 不会被插入或发送；选完后回到空输入框，再写
真正的任务，发送即开始一次性派遣。

若你现在能读到本段内容，说明发送前代理没有启用：

- 不要替 Claude 完成任务，也不要显示编号配置列表。
- 告诉用户运行项目范围同步器和 `activate-composer.mjs install`，再从新终端启动
  Codex，并确认 Codex 已信任当前项目。
- 不要把 `$claude` 当成消息发送；如果它已经到达模型，必须停止且不得派遣。
- 正确流程始终是：在补全菜单选择 `$claude` → 选完全部配置 → 写任务 → 只发送任务。
- 每个新任务和追问都必须重新选择 `$claude`；配置不会粘住。
